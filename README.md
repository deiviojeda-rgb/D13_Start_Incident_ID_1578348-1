## Chapter I

### Introduction

Предпросмотр README.md на платформе в задании участника и в GitLab может отличаться.
Для того чтобы отличия были минимальными вот несколько обязательных требований:

1. Используй [markdown](https://www.markdownguide.org/basic-syntax/) соглашение для заполнения README.md;
2. Не используй в README.md HTML код;
3. Так как платфома становится мультиязычной - создавай README.md на английском языке. В случае публикации двух и более языков README.md автоматически будет считаться английским.
4. Используй только нижний регистр для названия бинарных файлов;
5. Используй гиперссылки для методов в виде .[function](https://www.markdownguide.org/basic-syntax/)().
